Bugs found and fixed in the rewrite:
- `if targets:` on a tensor -> ambiguous-truth error. Fix: `if targets is not None:`.
- Position embedding indexed by token ids instead of `torch.arange(T)` -> index out of bounds. On MPS the error surfaced late (at exit), because the GPU runs asynchronously; run on CPU to get the error on the exact line.
- Silent: softmax over `dim=1` (the query axis) on (B,T,T) -> columns sum to 1, not rows. Would have trained to a worse loss with no crash. Fix: `dim=-1`. Fourth species of silent bug: right op, wrong axis.
- Silent: `generate` cropped into the same variable and never wrote the new token back -> model kept predicting from the original context. Fix: crop a copy (`x_cond`), grow the full sequence (`x = cat(x, x_next)`).
- Generation and final eval with dropout on / final model never evaluated (carried over from v2 review). Fix: `model.eval()` + `torch.no_grad()`; `for ... else:` runs one eval after the last step.

Concepts nailed down: wei[i, j] = query i's score against key j (row = asker, column = looked-at); only W_q W_k^T matters; scale by head_size^-0.5; positional embeddings because attention is permutation-invariant; multi-head = independent routing at equal cost; `proj` (W^O) mixes the heads and writes into the residual stream; every sub-layer (attention, FFN) has its own residual; lm_head = language-model head; FLOPs per token ≈ 2P; KV cache = 2 · n_layers · n_embd numbers per token.

Open (understood as a rule, rationale deferred to the GPT-2 video / CS336 lecture 3):

- Dropout placement: at the end of each sub-layer before the add, plus on attention weights; never on the stream. Why it goes to 0 at GPT-2 scale.
