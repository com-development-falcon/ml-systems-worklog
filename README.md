# ML Systems worklog

Public record of my path to a Research Engineer, ML Systems role. Each entry says what I tried, what I measured, and what's next. Dev on a Mac Studio; anything with a number in it was measured on rented Nvidia GPUs.

Entries are in `worklog/`, one file per entry, dated. Hours are in `HOURS.md`.

Rules I hold myself to:
- One track. Nothing here that isn't on the plan.
- Measure, don't assert. Every performance claim has a number and a method.
- Nothing ships without a writeup.
